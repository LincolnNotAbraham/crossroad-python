# Contribuindo para o Mini Crossy Road

Obrigado por interesse em contribuir!

## Como Contribuir

1. Faça um **fork** do repositório
2. Crie uma branch para sua feature (`git checkout -b nova-feature`)
3. Faça suas alterações
4. Faça commit com mensagens claras (`git commit -m 'Adiciona nova feature'`)
5. Push para a branch (`git push origin nova-feature`)
6. Abra um **Pull Request**

## Sugestões

- Novos obstáculos (ônibus, pedras)
- power-ups
- Diferentes cenários/fases
- Melhorias visuais
- Otimização de performance

## Regras

- Não quebre funcionalidades existentes
- Mantenha o estilo do código consistente
- Teste antes de enviar o PR
